# IBM Data Analyst — Learning Notebooks

Personal historical course/lab repository. Its name does **not** establish course completion, professional accreditation, IBM affiliation, or an active client engagement.

## Contents

Notebooks in the repository cover Python/HTTP requests, jobs-data API retrieval, web scraping, dataset exploration, data wrangling, exploratory data analysis, and visualization. Supporting artifacts include CSV/JSON/sample output files and example job-posting spreadsheets.

Open the corresponding `IBM_DA_*.ipynb` notebook to inspect methods and assumptions before reusing any result. Reproducibility, APIs, credentials, license and dataset use have not been verified in this documentation pass.
